## MODIFIED Requirements

### Requirement: 按需读取工件和文档

工作台 MUST 允许用户选择 change 并阅读其可用的规划工件和规范，包括 Markdown 文档和自定义 schema 的工件路径。工作台 MUST 按需加载完整文档内容，保留文档 identity 和 freshness 信息，并在文档过大、不可读、已删除或无法安全解析时提供易于理解的错误或 fallback。文档读取结果 MUST 提供可比较的 revision 或等价变化标识；当内容超过展示上限时 MUST 明确说明已展示范围、原始大小和继续读取或重试路径，不得静默把部分内容当作完整文档。对于符合 Markdown task-list 语法的列表项（`- [x]`、`- [X]`、`- [ ]`，允许既有缩进和 `*` 无序列表形式），工作台 MUST 在预览中保留并展示每项的已完成或未完成状态；该状态 MUST 与任务文本保持对应，不得因为安全文本渲染而丢弃。任务状态预览 MUST 是只读的，不得通过点击、键盘或其他预览交互修改 Workspace 中的任务文件或触发写请求。非 task-list 的普通列表、代码块和其他 Markdown 文本 MUST 保持原有可读呈现和安全边界。

#### Scenario: 用户打开 change

- **WHEN** 用户从总览中选择一个 change
- **THEN** 工作台在可导航的列表-详情阅读器中展示其可用工件和规范文档

#### Scenario: 用户选择工件

- **WHEN** 用户选择一个可读的工件文档
- **THEN** 工作台加载并渲染其 Markdown 内容，同时显示文档路径以及当前 freshness/provenance 状态

#### Scenario: 阅读期间文档发生变化

- **WHEN** 文档在加载后发生变化，或刷新使其 generation 失效
- **THEN** 工作台将已展示内容标记为 stale，在新数据可用前保留旧内容，并提供明确的刷新路径

#### Scenario: 文档无法读取

- **WHEN** 选中的文档缺失、过大、被拒绝访问、是二进制文件或不适合安全渲染
- **THEN** 工作台展示文档范围内的错误，包含路径和已知原因，并提供重试或返回列表的操作，不得影响整个工作台

#### Scenario: 文档超过客户端展示上限

- **WHEN** Host 返回的文档超过 Client 的安全展示上限
- **THEN** 工作台明确显示已展示的范围、原始大小和继续读取或重试路径；用户不得误以为当前文本是完整内容

#### Scenario: 用户选择包含混合任务状态的 tasks 文档

- **WHEN** 用户选择的工件正文包含 `- [x]`、`- [X]` 和 `- [ ]` 任务列表项
- **THEN** 工作台在对应任务文本旁分别展示已完成、已完成和未完成的只读视觉状态，且每项状态与原始顺序和文本对应

#### Scenario: 任务列表包含缩进或星号形式

- **WHEN** tasks 文档使用既有缩进层级，或使用 `* [x]` / `* [ ]` 作为无序列表标记
- **THEN** 工作台保留列表层级和每个 task-list 项的完成状态，不将其降级为没有状态的普通文本

#### Scenario: 用户尝试操作任务状态预览

- **WHEN** 用户点击、聚焦后按键或以其他方式操作任务状态控件
- **THEN** 控件不可编辑、不会改变视觉状态、不会发起 Host 写请求，文档内容仍保持只读

#### Scenario: 普通列表与代码文本包含类似标记

- **WHEN** 普通 Markdown 列表或 fenced code block 中出现不应作为 task-list 处理的 `[x]` / `[ ]` 文本
- **THEN** 工作台只在符合 task-list 列表语法且位于代码块之外的项目上展示任务状态，其他文本按原内容安全显示

#### Scenario: 任务文档发生刷新或读取失败

- **WHEN** tasks 文档在加载后发生 revision/generation 变化，或文档读取进入 stale、error、timeout 或 unavailable 状态
- **THEN** 工作台继续遵循既有文档 freshness、截断、错误和重试语义，同时不把任务状态预览解释为新的权威 workflow 状态或可写编辑能力
